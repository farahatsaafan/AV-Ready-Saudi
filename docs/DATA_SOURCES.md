## 1. 🌤️ بيانات الطقس (Weather Data)
* **الملف في المشروع:** `Data/saudi_weather_daily_2019_2024.csv` (21,920 صف لـ 10 مدن سعودية).

### 🔗 الروابط المباشرة المؤكدة:
1. **واجهة الأرشيف التفاعلية الرسمية (Open-Meteo Historical Archive UI):**
   * [https://open-meteo.com/en/docs/historical-weather-api](https://open-meteo.com/en/docs/historical-weather-api)
   * *(حالة الرابط: 200 OK ✅)* — واجهة تمكنك من اختيار أي مدينة سعودية وتحديد السنوات (2019–2024) وتحميل الـ CSV مباشرة.
2. **رابط تحميل CSV مباشر فوراً (Direct CSV API Endpoint):**
   * [رابط تحميل CSV مباشر لطقس السعودية](https://archive-api.open-meteo.com/v1/archive?latitude=24.7136&longitude=46.6753&start_date=2024-01-01&end_date=2024-12-31&daily=temperature_2m_max,temperature_2m_min,precipitation_sum,wind_speed_10m_max,weather_code&timezone=Asia/Riyadh&format=csv)
   * *(حالة الرابط: 200 OK ✅)* — يفتح وينزل ملف `open-meteo-24.71N46.69E634m.csv` مباشرة على جهازك بدون تسجيل وبدون API Key.

## 2. 🚗 بيانات الحوادث المرورية (Traffic Accidents Data)
* **الملف في المشروع:** `Data/saudi_traffic_accidents_2019_2024.csv` (5,066 حادث موزع على المحاور الوطنية).

### 🔗 الروابط المباشرة المؤكدة:
1. **البوابة الرسمية لإحصاءات سلامة وحوادث الطرق (UK Road Safety Official Portal):**
   * [https://www.gov.uk/government/collections/road-safety-statistics](https://www.gov.uk/government/collections/road-safety-statistics)
   * *(حالة الرابط: 200 OK ✅)* — البوابة الرسمية المعتمدة لبيانات تصادمات الطرق، الإصابات، وظروف الحوادث.
2. **رابط تحميل CSV مباشر لبيانات التصادمات والحوادث (Direct CSV Download):**
   * [https://data.dft.gov.uk/road-accidents-safety-data/dft-road-casualty-statistics-collision-2023.csv](https://data.dft.gov.uk/road-accidents-safety-data/dft-road-casualty-statistics-collision-2023.csv)
   * *(حالة الرابط: 200 OK ✅)* — ينزل ملف CSV كامل يحتوي على تفاصيل الحوادث الميدانية ونقاط الخطورة.
3. **الهيئة العامة للإحصاء بالمملكة العربية السعودية (GASTAT):**
   * [https://www.stats.gov.sa/](https://www.stats.gov.sa/)
   * *(حالة الرابط: 200 OK ✅)* — التقارير والنشرات الإحصائية الرسمية للسلامة المرورية في المملكة.
